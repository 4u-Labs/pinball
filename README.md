## ⚡ Visão Geral

Uma recriação fiel e otimizada do lendário **3D Pinball: Space Cadet** para rodar diretamente em navegadores modernos via **WebAssembly (WASM)** e **HTML5 Canvas**, sem necessidade de emuladores pesados ou plugins.

### 🌟 Principais Recursos:
* 🚀 **Performance Nativa a 60 FPS:** Execução via binário compilado em WebAssembly (`.wasm`).
* 🕹️ **Gabinete Arcade Customizado:** Moldura retrô (Bezel) com iluminação dinâmica e visual de fliperama clássico.
* 📱 **Suporte a Controles Táteis e Teclado:** Jogue no celular/tablet com toque nas laterais ou no teclado físico (`Z`, `/`, `Espaço`).
* 🔊 **Áudio Sintetizado & Efeitos Originais:** Sons clássicos das missões, rampas e bumpers.
* 💾 **PWA Offline:** Instale como aplicativo no celular ou computador e jogue mesmo sem internet.

---

## 💻 Stack Tecnológica

* **Motor Gráfico:** WebAssembly (WASM), Emscripten Engine, HTML5 2D Canvas
* **Interface & Áudio:** JavaScript ES6+, Web Audio API, CSS3 Neon Arcade
* **Distribuição:** Progressive Web App (PWA), Service Worker Cache
